# reuse: shingle-level duplication and within-crate type ownership

0.3.8 adds the reuse component. no-copy-paste: 5-line normalized shingles over live source (comments/whitespace/literals stripped; the digest stores no bodies) — a file pair needs >= 2 shared runs to fire; one shared truth (pragmas/serials) is not a copy. single-owner: one symbol one home is defined narrowly after an honor-test dogfood run produced 15 phantom collisions -- fn names repeat idiomatically across containers and cross-crate type names are normal namespacing; the check narrowed to declared types (struct|enum|trait) declared twice within ONE crate, Info default. The undogfooded first draft would have cried wolf 15 times, which is how advisory checks die; the narrowing is the check's honesty. Dogfood: the tool flagged its own CLI/MCP add-rule duplication (19 shared blocks in main.rs vs tools.rs) -- a real finding, left visible as the canonical example.
