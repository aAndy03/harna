# adopt refreshes adopted repos instead of refusing; parity history lives in a leaf module (0.3.43)

Adopt: on a repo with a non-empty manifest, harna adopt (CLI + MCP, one core adopt::run) prints a refresh — unregistered modules as paste-ready stanzas, modules outside every container, stale component paths, pathless containers — and still writes nothing. Rejected: a separate --refresh flag (the refusal was the only behavior there, so the plain command doing the useful thing is strictly better) and writing the stanzas (adoption is a human prune; the draft stays a proposal). Glue (lib/main/mod/build.rs) and test files are never proposed. Parity history: earlier hand verdicts (ack/noop) are kept per target, capped at 8, carried across re-opens. The Amendment type lives in parity/history.rs as a leaf because putting it in resolve.rs made parity.rs <-> resolve.rs an import cycle (no-cycles caught it). Numeric budgets: component-granularity, hotspot and transiter-thinness take a bound limit; a limit nothing reads is named by validate.
