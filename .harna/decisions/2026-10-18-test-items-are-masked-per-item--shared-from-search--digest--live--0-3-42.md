# Test items are masked per item, shared from search::digest::live (0.3.42)

Context: every source scan (gateway, URL check, digest extractor) stopped at the first #[cfg(test)]/#[test]/mod tests line, so a top-of-file '#[cfg(test)] use ...;' exempted the whole file — the font-manager probe's std::fs::read was missed this way, and the URL check exempted its own source. Decision: one brace-matching mask, search::digest::live::live_code, skips each gated item and resumes; it lives in the search layer so both the extractor (search) and the checks (integrity, which may reach search) share it. Extractor bumped to v5 (maps rebuild once). Rejected: patching each loop separately (four copies drift); a syn parse (heavy dependency, slow on big trees). Known limit: brace counting is lexical — raw strings with unbalanced braces inside a test item can end the mask early (fails toward checking more, not less).
