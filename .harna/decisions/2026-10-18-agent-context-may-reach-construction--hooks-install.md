# agent-context may reach construction (hooks install)

0.3.36 adds harna hooks install. The files come from generation::hooks (construction: the fs:write owner); wiring git core.hooksPath is a process call, which construction does not own. The orchestrator therefore lives in composition::hook_setup (agent-context, a process gateway) and needs generation. agent-context.depends_on gains construction rather than duplicating the orchestration in both interface surfaces (CLI + MCP). Composition reaching down is the stated layer doctrine; this only declares the edge. Also decided: the Claude Code hooks are installed only when the user runs hooks install (never implicitly), harna-managed files carry a marker and user files are never overwritten without --force, and the git gate fails CLOSED when no harna binary is found (bypass: HARNA_SKIP_HOOK=1) — the old hand-written hook silently passed.
