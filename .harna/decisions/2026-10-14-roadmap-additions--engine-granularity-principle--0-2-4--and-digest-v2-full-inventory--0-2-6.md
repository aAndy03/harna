# Roadmap additions: engine-granularity principle (0.2.4) and digest v2 full inventory (0.2.6)

Principle recorded: variants live in the primitive engine; an engine is its container, so variants are added inside the engine's own folder (new file, modification, or both), registered in the manifest, and consumed via the engine's API — forking logic in the importing file is the violation. A component that grows beyond one concern becomes its own container (cram check enforces size/complexity signal as Info). Dogfood: validate.rs becomes the validate/ container. Digest v2: items with visibility tags, impl method signatures, declared submodules (mods), private-move diff class; fan-out stays pub-driven because Rust visibility is the propagation boundary; digest.json stays one diffable artifact with hierarchy encoded as data and tree rendering on demand.
