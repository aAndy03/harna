# structure invariants as checks: no-cycles and engine homes

0.3.6 adds the structure component: no-cycles reports each cycle as the ring (deterministic rotation so one ring reports once) and engine-own-container gates engine-family file placement by opt-in role data on Container. Design choices: role = engine is a Container field (additive serde Option) because 0.3.25 makes roles mandatory later — the data precedes its consumers, per the roadmap sequencing; engine detection is by file-leaf prefix `<engine>-` (documented heuristic, keeps false positives low); cross-crate edges map package names to directories via workspace Cargo.tomls so multi-crate cycles are visible too. Dogfood: harna's own 41-module map declares no cycles — the claim is made by the tool checking itself.
