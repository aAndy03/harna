# Cost experiment — WITH harna 0.9.3 (2026-10-20)

**Cost** (from the run result): 106,338 tokens, 30 tool calls, 4 min 55 s. Control: 86,159 tokens, 10 tool calls, 2 min 46 s.

Product: Rust workspace, 6 crates — `domain` (Money in minor units, Posting), `storage`
(in-memory store), `app` (post_entry / apply_event use cases), `events` (the one shared
`PostingCreated { account, amount_minor }`), bins `api` and `worker` (api reads
`account amount` lines, emits encoded events on stdout; worker consumes them on stdin and
keeps a balance projection). `cargo build` / `cargo test` pass, 1 test per crate (6),
smoke pipe `api | worker` printed `cash=100`, `cash=70`. Scratch project deleted afterwards.

## Harna structure declared

- Layers: domain (base), events (transit), storage -> domain, application -> domain,storage,events,
  services (isolated) -> application,events,domain,storage.
- Containers: ledger-domain, ledger-events, ledger-store, ledger-app, api, worker (one component each).
- Services: `api` [api], `worker` [worker]; corridor `posting-events` (event) api -> worker carrying
  `PostingCreated=crates/events/src/posting_created.rs::PostingCreated`.
- 1 rule (layer-boundary, scope crates), 1 decision (services are composition roots), deny.toml generated.

## What harna made cheaper / more expensive

Cheaper:
- Crate boilerplate: `scaffold --new-crate lib` created Cargo.toml, lib.rs, workspace member and
  `pub mod` wiring in one call per crate (saved ~4 file writes/edits per lib crate).
- Probes: one `validate --changed` per break gave file:line + named rule; probe 3 (dependency
  without import) and probe 4b (forked event copy) are invisible to cargo — harna is the only catcher.
- First validate surfaced a real undeclared reach (services -> storage) that forced an explicit
  decision instead of a silent dependency.
- `affected`/`dependents` answered "who breaks" without reading code (~200 tokens each).

More expensive:
- Learning cost: ~13 KB (~3.3k tokens) of `--help` before the first line of code; ~15 help invocations.
- `harna plan` on an empty repo returned ~450 tokens of generic text (zero project value).
- Scaffold rough edges cost ~4 extra calls: `--path` with a single `--name` is a file path (wrote
  `crates/domain/src.rs`), and `--new-crate bin` collides with its own main.rs, leaving the
  container unregistered with an error that does not say so.
- Corridor cannot be declared before the message type exists (one failed call, re-run later).
- Noise: 7 info findings on the first validate (rules-coverage x6, deny-sync) ~500 tokens; had
  to add a rule just to quiet coverage. deny.toml generated but cargo-deny not installed.
- Gap: corridor-shape and parity-open depend on digest freshness — forgetting `harna scan`
  makes the drift probe PASS, and running `scan` makes the parity-open hint for a changed
  public signature vanish (the two behave in opposite directions w.r.t. scan).
- Overall: ~10 of 27 shell calls and ~4-5k tokens were harna setup/learning overhead; the probes
  themselves were cheap (1 call each).
